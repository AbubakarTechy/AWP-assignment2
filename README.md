
A Single Page Application built with React that allows users to browse, search, and manage local services like hospitals, restaurants, and parks.

## 🚀 Tech Stack 
 
- React (Vite)
- React Router DOM
- Context API
- Axios
- Tailwind CSS

## ✨ Features

- Browse local services fetched from API
- Search services in real time
- Add new services via form
- Delete services
- Loading & error handling
- Fully responsive UI

## ⚙️ Installation

```bash
git clone https://github.com/AbubakarTechy/localservice-finder.git
cd localservice-finder
npm install
npm run dev
```
